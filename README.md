# Spring Boot Auth Service
A production-style authentication and authorization service built with Spring Boot.

## Tech Stack

- Java 21
- Spring Boot 3
- Spring Security 6
- JWT Authentication
- PostgreSQL
- Spring Data JPA
- Maven
- Docker
- JUnit 5
- Mockito
- GitHub Actions

## Features

- User Registration
- User Login
- JWT Authentication
- Refresh Tokens
- Role-Based Authorization
- Password Encryption
- Email Verification
- Password Reset
- API Documentation (Swagger/OpenAPI)
- Dockerized Deployment
